# Comparativa de Sintaxis: Python, JavaScript y C#

| **1. Imprimir en consola** | `print("Hola")` | `console.log("Hola");` | `Console.WriteLine("Hola");` |
| **2. Declarar variables** | `nombre = "Dainer"` | `let nombre = "Dainer";` | `string nombre = "Dainer";` |
| **3. Leer datos de entrada** | `dato = input()` | `let dato = prompt();` | `string dato = Console.ReadLine();` |
| **4. Condicional (If)** | `if x > 0:` | `if (x > 0) { }` | `if (x > 0) { }` |
| **5. Bucle repetitivo (For)** | `for i in range(5):` | `for (let i = 0; i < 5; i++) { }` | `for (int i = 0; i < 5; i++) { }` |
| **6. Comentarios** | `# Comentario` | `// Comentario` | `// Comentario` |
